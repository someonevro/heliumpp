# Helium++ logo — usage

**Idea:** a balloon whose shine is a plus. Helium lifts balloons; the plus is the "++".

## Files
| File | Use |
| --- | --- |
| `heliumpp-symbol.svg` | Main mark, 32 px and up |
| `heliumpp-symbol-small.svg` | 24 px and below (no knot, bigger plus) |
| `heliumpp-horizontal.svg` / `heliumpp-stacked.svg` | Logo with name |
| `heliumpp-wordmark.svg` | Name alone (letters drawn as paths, no font needed) |
| `variants/` | Black, white, rose, favicon, app icon, web icon set |
| `presentation.html`, `slides/` | Presentation board |

Browser assets are rendered from these by `scripts/make_branding.sh` into `branding/`.

## Colour
| Name | HEX | RGB | Contrast |
| --- | --- | --- | --- |
| Helium rose | `#D9435F` | 217 67 95 | 4.3:1 on white, 3.9:1 on #1E1E1E |
| Ink | `#221C2B` | 34 28 43 | 16.6:1 on white |

The symbol is rose; the name is ink (white on dark). One-colour black or white is always allowed.

## Rules
- **Clear space:** the width of the plus arm on every side.
- **Minimum size:** main mark 32 px; below that use the small cut. Lockup at least 22 px tall.
- **Background:** the plus is a hole, so the background shows through. Keep it plain.
- **Don't:** recolour the plus separately, add shadows or gradients, rotate, stretch, or redraw the letters in a font.
